# Expanded Root Audit

This file is the working audit for the separate expanded root database.

## Taxonomy

- `Established root`: already present as a root entry in `data/roots_and_morphology.csv`
- `Established morpheme`: already present as a non-root morpheme/particle/suffix entry in `data/roots_and_morphology.csv`
- `Promoted root`: attested in the canon lexicon and productive enough to promote into the expanded root database
- `Promoted morpheme`: not yet formalized in the root database, but useful and recoverable from attested behavior
- `Created root`: intentionally introduced for the expanded root database rather than directly recovered from an existing root entry
