# Week 8, Lesson B: Build upward

**Objective:** Read a mixed number and a scaled number.

**Source links:** [Grammar Guide](../../dictionary/app_data/grammar_guide.csv) · [Dictionary headwords](../../dictionary/app_data/dictionary_entries.csv) · [Dictionary examples](../../dictionary/app_data/dictionary_examples.csv) · [Expressions](../../dictionary/app_data/expressions_app.json).  
**Grammar topics:** Numbers and Basic Math, Number building examples. **Focus forms:** `Tenar`, `Quen`.

**Suggested session:** 3 minutes with models, 10 minutes practice, 8 minutes independent use, then a brief review.

## Model and explanation

| Celan | Meaning |
| --- | --- |
| `Tenar unar` | eleven |
| `Hek-quen Ten-peth` | four hundred fifty |

Larger unit first: ten plus one, then hundreds before tens.

## Practice

### Build Words

2. Write the Celan form for **four**.

### Read, build, and fix meaning

3. Read model A. What does it mean in English?

## Independent task

Read a count of eleven and a count of four hundred fifty. Use the two models as choices or frames; answer without looking.

## Hint

Separate the larger unit from the added part.

## Answer key and feedback

2. **`Quen`.**
3. **eleven**
4. **four hundred fifty**
5. **11**
6. **450**

**Independent response guide:** Tenar unar is eleven; Hek-quen Ten-peth is four hundred fifty.
