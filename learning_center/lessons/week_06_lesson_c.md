# Week 6, Lesson C: Ask where

**Objective:** Use an explicit place-question tail when needed.

**Source links:** [Grammar Guide](../../dictionary/app_data/grammar_guide.csv) · [Dictionary headwords](../../dictionary/app_data/dictionary_entries.csv) · [Dictionary examples](../../dictionary/app_data/dictionary_examples.csv) · [Expressions](../../dictionary/app_data/expressions_app.json).  
**Grammar topics:** Optional content-question tails. **Focus forms:** `Ra`, `Lo`.

**Suggested session:** 3 minutes with models, 10 minutes practice, 8 minutes independent use, then a brief review.

## Model and explanation

| Celan | Meaning |
| --- | --- |
| `ra var ser?` | Where does the friend go? Context supplies place. |
| `ra var ser lo?` | Where does the friend go? Lo makes place explicit. |

Both questions can be grammatical; lo explicitly names the missing place.

## Independent task

Ask a companion where the friend goes in a noisy scene. Use the two models as choices or frames; answer without looking.

## Hint
