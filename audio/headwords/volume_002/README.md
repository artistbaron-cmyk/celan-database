# Headword audio · volume 002

This volume contains the next 200 unique dictionary headword MP3s, originally recorded with Ehshara and `eleven_v4` in seven internal passes of 30, 30, 30, 30, 30, 30, and 20 clips. Filenames start with the stable `HW-` headword ID. [manifest.csv](manifest.csv) maps each MP3 to the written word, dictionary pronunciation, generation prompt, voice, generation ID, duration, source pass, review state, and checksum.

Slot 64 now contains **Oshen** (`/ohshehn/`), recorded with Ehshara on 2026-10-16 after the spelling change from `-eshen` to `-oshen`. The earlier Eshen recording is retained under `superseded/` and is not part of the current 200 clips.

All active clips in this volume were approved for app playback on 2026-10-16. The `aen` words use individually prepared no-H prompts based on the user's approved **Rinaen** and **Aen** examples; `x` words use KS prompts chosen by the user. These are speech inputs, not changes to the dictionary spelling or phonetic records. Technical validation confirms file decodability and manifest correspondence, not pronunciation approval.

All active clips in this volume are linked to the local dictionary app. [Volume 003](../volume_003/README.md) contains the next 200 headwords.
