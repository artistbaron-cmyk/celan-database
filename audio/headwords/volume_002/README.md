# Headword audio · volume 002

This volume contains the next 200 unique dictionary headword MP3s, recorded with Ehshara and `eleven_v4` in seven internal passes of 30, 30, 30, 30, 30, 30, and 20 clips. Filenames start with the stable `HW-` headword ID. [manifest.csv](manifest.csv) maps each MP3 to the written word, dictionary pronunciation, generation prompt, voice, generation ID, duration, source pass, review state, and checksum.

Listening review: 11 clips are marked `ERROR_` and `Needs correction` by the user; 189 remain pending. The `aen` words use individually prepared no-H prompts based on the user's approved **Rinaen** and **Aen** examples; `x` words use KS prompts chosen by the user. These are speech inputs, not changes to the dictionary spelling or phonetic records. Technical validation confirms file decodability and manifest correspondence, not pronunciation approval.

No clips are integrated into the dictionary app. [Volume 003](../volume_003/README.md) contains the next 200 headwords.
