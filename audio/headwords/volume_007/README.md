# Headword audio · volume 007

This volume contains 200 unique dictionary headword clips recorded with Ehshara and `eleven_v4`. [manifest.csv](manifest.csv) maps each MP3 to its dictionary source, speech prompt, generation ID, duration, review state, and checksum.

ElevenLabs returned `daily_generation_limit_reached` after the first 99 clips. The interrupted pass was completed as `pass_04a` and `pass_04b`, followed by passes 05–07. The [completed journal](.completed_batch_007.json) records all 200 headwords. A file and manifest audit found 200 matching, decodable MP3s in this volume and 1,400 unique headwords across volumes 001–007.

All recorded clips await human listening review. The dictionary text was not changed, and no clips are integrated into the dictionary app.
