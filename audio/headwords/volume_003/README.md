# Headword audio · volume 003

This volume contains the next 200 unique dictionary headword MP3s, recorded with Ehshara and `eleven_v4` in seven internal passes of 30, 30, 30, 30, 30, 30, and 20 clips. Filenames start with the stable `HW-` headword ID. [manifest.csv](manifest.csv) maps each MP3 to the written word, dictionary pronunciation, generation prompt, voice, generation ID, duration, source pass, review state, and checksum.

Listening review: 6 clips are marked `ERROR_` and `Needs correction` by the user; 194 remain pending. The 51 words containing `aen` or `x` use individually prepared no-H or KS speech prompts based on the user's earlier pronunciation choices. The dictionary spellings and phonetic records were not changed. Technical validation confirms file decodability and manifest correspondence, not pronunciation approval.

No clips are integrated into the dictionary app. [Volume 004](../volume_004/README.md) contains the next 200 headwords.
