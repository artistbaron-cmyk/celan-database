# Headword audio · volume 006

This volume contains 200 unique dictionary headword MP3s recorded with Ehshara and `eleven_v4` in seven internal passes. Filenames start with the stable `HW-` headword ID. [manifest.csv](manifest.csv) maps each MP3 to its written word, dictionary pronunciation, generation prompt, voice, generation ID, duration, source pass, review state, and checksum.

All 200 clips await human listening review. Words containing `aen` or `x` use individually prepared no-H or KS speech prompts based on the user's earlier pronunciation choices. Technical validation confirms file decodability and manifest correspondence, not pronunciation approval. The dictionary text was not changed.

No clips are integrated into the dictionary app. [Volume 007](../volume_007/README.md) is in progress.
