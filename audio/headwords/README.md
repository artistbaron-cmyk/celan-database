# Celan headword audio pilot

The first volume contains 10 Ehshara / `eleven_v4` takes for unique dictionary headwords. Each filename begins with `HW-` and the stable `dictionary/app_data/dictionary_entries.csv` headword ID. The [volume manifest](volume_001/manifest.csv) records the written headword, dictionary pronunciation, actual ElevenLabs prompt, generation ID, voice, duration, checksum, and review state.

These are isolated word takes for the user's listening review. The prompt uses `-ee` for standalone **I**, `Ehlan` for **Elan**, and `ks` for written **x**, reflecting the user's successful speech-input trials. The dictionary's written pronunciations for X words currently use KH; the pilot deliberately tests the user's preferred KS sound. Written headwords and dictionary data were not changed.

The clips are not integrated into the dictionary app. Do not scale this pilot until the user has listened and chosen which pronunciations and voice delivery to keep.
