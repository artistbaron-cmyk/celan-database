# Aen pronunciation trials

Four Ehshara / `eleven_v4` alternatives test the user's requested substitutions for written `aen`: `ahen` and `a-en`. There are two takes for **Rinaen** and two for **Aen**, each with the exact speech prompt and generation ID in [aen_variants.csv](aen_variants.csv).

The first alternatives were separate listening trials and were not integrated into the app. Do not apply their substitutions across other headwords.

After the user reported that `ahen` made the H audible and neither first alternative worked, [no_h_variants.csv](no_h_variants.csv) records four further trials: inline IPA and a spelling without H for each of **Rinaen** and **Aen**. ElevenLabs v4 supports inline IPA between slashes.
The user selected the no-H spelling takes (`Ree-na-en`, `Aa-en`) on 2026-10-15. Those exact MP3s were copied to `../volume_001/` under the stable canonical filenames. The former canonical MP3s are preserved here as `HW-rinaen - original pilot.mp3` and `HW-aen - original pilot.mp3`. The IPA and earlier spelling alternatives were not selected.
