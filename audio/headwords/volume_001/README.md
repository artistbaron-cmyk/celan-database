# Headword audio · volume 001

This volume contains 200 unique dictionary headword MP3s: the original 10-clip pilot plus 190 clips recorded in seven internal passes. All use Ehshara and `eleven_v4`. Each filename starts with the stable `HW-` headword ID. See [manifest.csv](manifest.csv) for each word's written pronunciation, generation prompt, voice, duration, source pass, review state, and checksum.

Listening review: 2 clips approved by the user (**Rinaen** and **Aen**), 11 marked `ERROR_` and `Needs correction` by the user, and 187 pending human listening review. The `ERROR_` filenames are preserved and reflected in the manifest. Technical validation of MP3 decodability does not constitute pronunciation approval.

The approved **Rinaen** and **Aen** takes use the no-H prompts `Ree-na-en` and `Aa-en`. The original pilot takes remain in [pronunciation_trials](../pronunciation_trials/README.md). This batch uses selected pronunciation prompts for other `aen` and `x` words; their sounds still need listening review.

No clips in this volume are integrated into the dictionary app. Volume 001 is full; [volume 002](../volume_002/README.md) now contains the next 200 headwords.
