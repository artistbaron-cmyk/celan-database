# Headword audio · volume 001

This volume contains 200 unique dictionary headword MP3s: the original 10-clip pilot plus 190 clips recorded in seven internal passes. The original batches used Ehshara and `eleven_v4`. Each filename starts with the stable `HW-` headword ID. See [manifest.csv](manifest.csv) for each word's written pronunciation, generation prompt, voice, duration, source pass, review state, and checksum.

All active clips in this volume were approved for app playback on 2026-10-16. The superseded flagged recordings are preserved under `audio/retakes/superseded_originals`. Technical validation of MP3 decodability does not constitute pronunciation approval.

The approved **Rinaen** and **Aen** takes use the no-H prompts `Ree-na-en` and `Aa-en`. The original pilot takes remain in [pronunciation_trials](../pronunciation_trials/README.md). This batch uses selected pronunciation prompts for other `aen` and `x` words; their pronunciations may still receive feedback.

All active clips in this volume are linked to the local dictionary app. Volume 001 is full; [volume 002](../volume_002/README.md) now contains the next 200 headwords.
