# Headword audio · volume 008

This volume contains 99 unique headword clips: the 95 available on 2026-10-16 plus **nevu**, **arin**, **mbetu**, and **senu**. All four additions use Ehshara and `eleven_v4`. [manifest.csv](manifest.csv) maps every MP3 to its exact dictionary ID and spelling, speech prompt, generation ID, duration, review state, and checksum. The [completed journal](.completed_batch_008.json) records the original 95 entries.

Several dictionary entries are affixes (for example `-aen`) or list alternate forms. Their filename IDs use `__` in place of the source ID's ` / ` delimiter, while the manifest retains the exact ID. The original active clips were approved for app playback on 2026-10-16; the four new clips are first takes. Written dictionary data were not changed, and the active clips are linked to the local dictionary app.

No source headwords remain for volume 009 in `dictionary/app_data/dictionary_entries.csv`.
