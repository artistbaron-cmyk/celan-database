# Headword audio · volume 008

This volume contains the final 95 unique source headwords available on 2026-10-16, originally recorded with Ehshara and `eleven_v4`. [manifest.csv](manifest.csv) maps every MP3 to its exact dictionary ID and spelling, speech prompt, generation ID, duration, review state, and checksum. The [completed journal](.completed_batch_008.json) records all selected entries.

Several dictionary entries are affixes (for example `-aen`) or list alternate forms. Their filename IDs use `__` in place of the source ID's ` / ` delimiter, while the manifest retains the exact ID. All active clips in this volume were approved for app playback on 2026-10-16. Written dictionary data were not changed, and the active clips are linked to the local dictionary app.

No source headwords remain for volume 009 in `dictionary/app_data/dictionary_entries.csv`.
