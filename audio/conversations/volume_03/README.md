# Conversation Volume 3 — scene recordings

Volume 3 is about precision in everyday life: which object, how many, how much, and where. Each of the 30 standalone scenes has one MP3 named `scene_01_vernacular_take_01.mp3` through `scene_30_vernacular_take_01.mp3`. The number matches the scene in the [Celan and English guide](CELAN_AND_ENGLISH.md).

These are ElevenLabs Eleven v4 dialogue recordings. **Savi** is Lily, **Dalen** is Ayinde, and **Meva** is Ehshara. The [recording copy](../../../learning_center/everyday_conversations_volume_03_recording_copy.md) supplies a mood cue before every speaker turn, minimal punctuation, and sound spellings for pronunciation. The [learner script](../../../learning_center/everyday_conversations_volume_03_celan_vernacular.md) preserves written Celan and is the text to use for subtitles and teaching. In particular, written **I** is spoken **ee**.

All 30 files are present, nonempty, and readable as MP3 audio. They are first takes; listen for pronunciation and performance before release.
