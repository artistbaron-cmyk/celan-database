# CELAN Database Docs

This folder is the app-wide documentation home.

It exists to explain the whole system at a human level:

- what the major parts are
- how they relate to each other
- which files are source-facing
- which files are working layers
- where to look when something needs to be updated

The goal is not to restate every file. The goal is to make the project easier to understand and easier to maintain.

## What lives here

- `system_map.md`
  - The broad map of the project.

- `site_surfaces.md`
  - The public-facing parts of the app and what each one is supposed to do.

- `data_layers.md`
  - The difference between source files, clean copies, and working files.

- `maintenance_notes.md`
  - Practical notes about how to update the system without muddying it.
