# Workflow

This is the current working path for the Phrase Builder side.

It is intentionally modest. The goal right now is not to fake intelligence. The goal is to prepare strong support layers so future phrase work has real footing.

## Step 1: Start from canon

The source of truth stays the same:

- dictionary
- grammar guide
- cultural voice material

We build from them. We do not replace them.

## Step 2: Make working layers from the canon

Some canon files are good for reading but not good for support work.

So we build cleaner working layers around them, such as:

- phrasebank
- evaluation set
- concept companion
- working grammar source

These files are allowed to be shaped for use, as long as they stay honest about what they are.

## Step 3: Tighten those layers until they are actually usable

A support file is not finished just because it exists.

It should be:

- clear
- internally consistent
- grounded enough to trust
- shaped enough to use

This is where most of the real labor is happening right now.

## Step 4: Let the layers do their own jobs

Each support file exists for a different reason:

- phrasebank shows known phrasing
- concepts show meaning neighborhoods
- evaluation shows what good performance looks like
- working grammar shows usable rule structure
- docs explain how the whole support system fits together

If one file starts trying to do every job, the system gets muddy.

## Step 5: Use the support layer when phrase work resumes

When the phrase side becomes stronger later, it should be able to lean on this groundwork instead of guessing from loose vocabulary.

That future system should be able to look toward:

- phrasebank for patterns
- concepts for semantic shape
- working grammar for sentence behavior
- evaluation for testing whether it actually improved

## Step 6: Keep honesty higher than elegance

Some files can be polished.
Some files can be instructional.
Some files can be compact.

That is fine.

What matters is that each file tells the truth about its own job and does not pretend to be more settled, more sourced, or more intelligent than it really is.
