# Phrase Builder Docs

This folder explains the Phrase Builder side in human terms.

The phrase side is not the canon itself. It is the support layer being built around the canon so that future phrase work has something real to stand on.

These notes exist to answer simple questions:

- what this part of the system is for
- what each support file does
- what standards we are trying to protect
- what still is not built yet

## What lives here

- `system_overview.md`
  - A plain-language map of the Phrase Builder support layer.

- `working_rules.md`
  - The standards that keep phrase work aligned with Celan instead of drifting into loose improvisation.

- `workflow.md`
  - The current path from canon material to usable phrase support.

- `build_concept_map_pdf.py`
  - Utility script for generating a polished PDF from concept material.

## What this folder is not

This folder is not:

- a replacement for the dictionary
- a replacement for the grammar guide
- a promise that the builder already works intelligently

The builder is still unfinished. These docs are here so the unfinished parts are at least legible, honest, and pointed in the right direction.
