# Working Rules

These are the rules that keep phrase work honest.

They are here because the danger is not only getting a phrase wrong. The bigger danger is sounding confident while quietly drifting away from Celan.

## 1. Canon first

If the system already contains the word, phrase, or support we need, we use it.

We do not paraphrase around something that already exists just because a looser answer sounds easier.

The working order is:

- exact canon first
- shaped phrasing second
- paraphrase last

## 2. If it is here, it is canon

The issue is not legitimacy.

The issue is form.

That means the real questions are:

- is the sentence moving like Celan
- is the phrasing natural to Celan
- is English structure leaking through
- is the tone doing the right kind of work

## 3. Do not invent absence

If the canon already gives us a word, the system should not talk as if the word is missing.

If a field is thin, we can say it is thin.
If a phrase needs reshaping, we can say why.
But we do not create fake uncertainty.

## 4. Explanations should help, not dump

The phrase side should explain results in a way that feels guided and readable.

It should tell the user:

- why this phrasing works
- what got reshaped from the English
- what the cultural lens changed, if one was used

It should not spill raw parts, clutter, or backstage scaffolding unless that detail actually helps.

## 5. Concept fields matter

Celan is not well served by shallow word swapping.

Many phrases live inside larger meaning neighborhoods, such as:

- longing
- relation
- balance
- protection
- movement
- ritual

The support layer should keep those fields visible so future phrase work has a better chance of sounding like Celan rather than English wearing Celan words.

## 6. Cultural voice shapes expression

Cultural voice matters.

It can shape:

- sound
- metaphor
- pacing
- formality
- emotional feel

But it should not be treated as if every nation is speaking a different grammar.

## 7. The support layer should be useful on its own

Every support file should make sense even before any future AI layer exists.

If a file is only tidy but not useful, it is not finished yet.
