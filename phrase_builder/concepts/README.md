# Concept Layer

This folder holds the broader conceptual map behind Celan.

The point of this layer is not to replace the dictionary. It is to show the deeper meaning fields the canon keeps clustering around: truth, balance, longing, relation, ritual, movement, creation, and so on.

Why this matters:

- the dictionary explains individual words
- the grammar guide explains how the language moves
- the concept layer explains the larger meaning-world those words live inside

For the Phrase Builder, this layer matters because many English phrases are not best solved word-by-word. They are better solved by understanding which Celan concept field the phrase belongs to.

The current first-pass map lives in:

- `concept_map.csv`

This map is a working conceptual spine, not a claim that Celan can be reduced to only a few abstract buckets. It is meant to help us see the broad canon architecture more clearly.
